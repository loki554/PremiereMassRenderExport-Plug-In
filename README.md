# Mass Marker Export — плагин для Premiere Pro

Массовый экспорт кусков секвенции в Adobe Media Encoder по маркерам.
Каждый маркер **с длительностью** = отдельный файл, имя маркера = имя файла.

## Установка

1. Запустите `install.bat` (копирует панель в `%APPDATA%\Adobe\CEP\extensions` и включает
   загрузку неподписанных расширений — `PlayerDebugMode`).
2. Перезапустите Premiere Pro.
3. Откройте панель: **Window → Extensions → Mass Marker Export**.

Удаление — `uninstall.bat`. После правок в коде снова запустите `install.bat`
и переоткройте панель.

Требования: Premiere Pro 2022+ (проверено на 2024 / 24.6) и установленный Adobe Media Encoder той же версии.

## Как пользоваться

1. **Разметка.** На таймлайне поставьте маркер (`M`), затем растяните его: Alt+перетаскивание
   правого края маркера или задайте **Duration** в диалоге маркера (двойной клик по маркеру).
   В поле **Name** впишите имя будущего файла. Маркеры без длительности игнорируются.
2. **Маркеры.** Нажмите «Обновить» (панель также обновляет список сама, когда вы на неё переключаетесь).
   Лишние отрезки можно снять галочкой или отфильтровать по цвету маркера.
3. **Пресет.** Выберите пресет из списка: сверху «Мои пресеты» (сохранённые в AME / Premiere),
   ниже системные, сгруппированные по формату. Есть поиск и кнопка «Файл .epr…» для любого пресета.
   Свой пресет удобно создать в Media Encoder: Preset Browser → «+» → Create Encoding Preset.
4. **Папка вывода.** Укажите путь (кнопка «Обзор…»). Если папки нет — она будет создана.
5. Нажмите **«Отправить в Media Encoder»**. Все отрезки встанут в очередь AME;
   если стоит галочка «Сразу запустить рендер» — рендер стартует автоматически.

Пресет, папка и опции запоминаются между сессиями.

## Правила имён файлов

- Недопустимые в Windows символы `\ / : * ? " < > |` удаляются.
- Маркер без имени → `<ИмяСеквенции>_<номер>`.
- Одинаковые имена → `Имя`, `Имя_2`, `Имя_3`…
- С опцией «Не перезаписывать» суффикс добавляется и тогда, когда файл уже есть в папке.
- Расширение берётся из пресета (`.mp4`, `.mov`, …).
- Строки с изменённым именем подсвечены жёлтым, причина — во всплывающей подсказке.

## Как это работает

Для каждого отрезка панель ставит In/Out секвенции на границы маркера и вызывает
`app.encoder.encodeSequence(..., ENCODE_IN_TO_OUT)`. После отправки всех заданий
исходные In/Out секвенции восстанавливаются. Premiere сохраняет копию секвенции для
каждого задания, поэтому отправка занимает несколько секунд на отрезок — прогресс
виден в панели.

## Структура

```
CSXS/manifest.xml   манифест CEP-расширения
index.html          разметка панели
css/style.css       стили
js/main.js          логика панели: маркеры, пресеты, имена, отправка
jsx/host.jsx        ExtendScript: чтение маркеров и работа с Media Encoder
.debug              отладка: Chrome DevTools на http://localhost:8088
```
